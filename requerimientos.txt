Introducción
Descripción General del Sistema
KuenteCO es un sistema integral de gestión financiera diseñado para usuarios particulares y negocios informales. Permite la administración eficiente de finanzas, facilitando la planificación, seguimiento y análisis de datos financieros. Es un aplicativo web y móvil accesible desde cualquier dispositivo con conexión a Internet.

Propósito del Documento
Este documento de Especificación de Requerimientos de Software (ERS) describe las funcionalidades y características de KuenteCO. Sirve como guía para desarrolladores, diseñadores y stakeholders, asegurando que los requisitos técnicos y de usuario sean comprendidos y atendidos adecuadamente.

Alcance del Sistema
KuenteCO incluye:
Gestión de Ingresos y Gastos: Registro y seguimiento de todas las transacciones financieras, tanto ingresos como gastos, con opciones para categorización y análisis.
Planificación Financiera: Herramientas para la creación de presupuestos, registro de transacciones y planificación de pago de deudas a corto y largo plazo.
Generación de Informes: Capacidades para generar informes detallados sobre la situación financiera del usuario, incluyendo gráficos y estadísticas personalizables.
Integración Bancaria: Conexión con cuentas bancarias para la importación automática de transacciones y el seguimiento en tiempo real.(A Considerar)
Alertas y Recordatorios: Alertas y recordatorios automatizados para eventos relevantes en la app.
Acceso Multiperfil: Soporte para múltiples perfiles, permitiendo a pequeños y medianos negocios gestionar las finanzas de manera colaborativa.
Seguridad y Privacidad: Implementación de protocolos de seguridad robustos para proteger los datos financieros de los usuarios.
Descripción General del Sistema
Contexto del Sistema
KuenteCO se integra como una herramienta central en la gestión financiera tanto de usuarios particulares como de pequeños y medianos negocios, brindando una solución completa y accesible para el control de sus finanzas.
Para un particular, KuenteCO actúa como un asistente personal de finanzas, facilitando el registro diario de ingresos y gastos, la creación de presupuestos, el seguimiento de deudas, registro de rubros y la generación de informes personalizados. Todo esto permite a los usuarios tener una visión clara de su situación financiera, tomar decisiones informadas y planificar para el futuro de manera efectiva.
En el contexto de un negocio pequeño o mediano, KuenteCO se convierte en una herramienta esencial para la gestión financiera empresarial. Permite a los negocios llevar un control detallado de sus transacciones, gestionar múltiples perfiles, generar reportes financieros cruciales para la toma de decisiones, y mantener un control efectivo sobre los gastos operativos y los ingresos. La capacidad de KuenteCO para integrar cuentas bancarias y automatizar la importación de transacciones reduce la carga administrativa, permitiendo a los propietarios de negocios concentrarse en otras áreas clave de su operación.
Usuarios y Roles
Kuenteco está diseñado para los siguientes tipos de usuarios:
1. Usuarios Finales:
   - Particulares: Usuarios individuales que gestionan sus finanzas personales.
   - Propietarios de Negocios: Personas o entidades que administran las finanzas de su negocio.
-Trabajadores de Negocios: Personal del negocio administrado por el propietario.
2. Equipo de Desarrollo y Soporte:
   - Desarrolladores: Encargados de la creación, mantenimiento y actualización del sistema.
   - Testers: Responsables de probar el sistema para garantizar su correcto funcionamiento.
   - Soporte Técnico: Personal encargado de brindar asistencia a los usuarios finales.

Suposiciones y Dependencias
 1. Suposiciones.  
   - Los usuarios tendrán conocimientos básicos de gestión financiera.  

   - El sistema será accesible desde dispositivos con conexión a Internet.  

   - Las instituciones bancarias proporcionarán APIs seguras para la integración. 
 
   - El sistema operará bajo una política de seguridad estricta.  
2. Dependencias:
   - Integración Bancaria: Kuenteco dependerá de las APIs proporcionadas en API Market Bancolombia para la importación automática de transacciones.
   - Servicios de autenticación: El sistema utilizará como servicio de autenticación a externos OAuth y para la gestión segura de usuarios y accesos utilizara JWT.
   - Infraestructura en la Nube: KuenteCO dependerá del servicio de ECS de AWS para el alojamiento, almacenamiento y escalabilidad del sistema.
   - Dependencias Tecnológicas: El sistema dependerá de tecnologías como Flutter (FRONT-END), y otras tecnologías como SpringBoot (BACK-END) y usará como bases de Datos PostgreSQL y MongoDB.

Gestión de usuarios
- Requerimiento Funcional: KuenteCO permitirá crear, eliminar, modificar y seleccionar entre cuenta particular o de negocio.
  - Historias de Usuario:
    Como usuario, 
    Quiero crear una cuenta, 
    Para usar la app Kuenteco
 
    Como usuario, 
    Quiero eliminar mi cuenta, 
    Para no figurar en Kuenteco
 
    Como usuario, 
    Quiero modificar mi cuenta, 
    Para actualizarla
 - Criterios de aceptación:
Los usuarios deben poder registrar una cuenta personal o de negocio.
Debe permitirse la edición de la información de la cuenta en cualquier momento.
El usuario podrá eliminar su cuenta y todos sus datos asociados.
Se debe permitir la gestión de múltiples cuentas dentro de una misma sesión.
Beneficio: Ofrece flexibilidad y control sobre la información personal del usuario, promoviendo la confianza en la plataforma y mejorando la experiencia del usuario (Laudon & Laudon, 2020).

Gestión Integral de Perfiles por el Usuario de Negocio
- Requerimiento Funcional: KuenteCO permitirá a los usuarios de negocio administrar completamente sus perfiles con capacidades de creación, listado y eliminación.
- Historias de Usuario:
Como usuario de negocio,  
Quiero crear nuevos perfiles,  
Para administrar mi negocio.

Como usuario de negocio,  
Quiero ver todos los perfiles existentes,  
Para tener una visión clara de los miembros.

Como usuario de negocio,  
Quiero eliminar perfiles que ya no son necesarios,  
Para mantener la base de datos de perfiles limpia y actualizada.

- Criterios de Aceptación:
El sistema debe permitir la creación de nuevos perfiles asociados a un negocio a través de un formulario con validaciones robustas de datos.
Cada perfil debe incluir un nombre de usuario, email único, contraseña segura, rol asignado automáticamente, imagen de perfil opcional, y fecha de inicio automática.
Las contraseñas deben cumplir criterios de seguridad: mínimo 8 caracteres, al menos 1 número, 1 minúscula, 1 mayúscula y 1 carácter especial.
Los usuarios de tipo PERSONAL no pueden crear perfiles adicionales.
Los usuarios con suscripción BASIC están limitados a 3 perfiles máximo.
El sistema debe mostrar una lista detallada de todos los perfiles asociados a un negocio, incluyendo información básica como nombre de usuario, email e imagen.
La vista de listado debe ser accesible solo para usuarios autenticados con rol de usuario de negocio.
Los cambios deben reflejarse inmediatamente en el sistema.
No se pueden duplicar nombres de usuario dentro del mismo negocio..
El usuario debe poder eliminar perfiles por ID.
Al eliminar un perfil, todos los datos asociados deben eliminarse de manera segura de la base de datos.
Los perfiles pueden iniciar sesión usando nombre de usuario o email con contraseña.
El sistema genera tokens JWT seguros para mantener las sesiones.
Cambio de contraseña mediante código de verificación enviado por email.
Implementación de blacklist de tokens para mayor seguridad.
Funcionalidad para actualizar imágenes existentes.
Integración con servicio de almacenamiento de imágenes.
Validación de formato de email.
Restricciones de caracteres para nombres de usuario (solo letras y espacios).
Verificación de límites de perfiles según tipo de suscripción.

Beneficios:
•  Gestión Organizacional Completa: Permite a los negocios gestionar eficientemente su estructura organizativa y roles.
•  Seguridad Robusta: Implementa autenticación segura con JWT, verificación por email y gestión segura de contraseñas.
•  Control de Acceso: Sistemas de roles y permisos que garantizan acceso apropiado según el tipo de usuario.
•  Personalización: Capacidad de personalizar perfiles con imágenes e información específica.
•  Escalabilidad: Restricciones basadas en suscripción que permiten crecimiento controlado.
•  Integridad de Datos: Validaciones exhaustivas que mantienen la calidad y consistencia de los datos.

Historias de Usuario:

Para organizar y controlar gastos según responsabilidades.

Como usuario de negocio, 
Quiero asignar presupuestos a cada categoría por perfil,

Como usuario de negocio, 
Quiero modificar las asignaciones de categorías y presupuestos por perfil, 
Para ajustar necesidades financieras según la operación del negocio.

Como usuario de negocio, 
Quiero eliminar asignaciones de categorías a perfiles que ya no las requieran, 
Para mantener la estructura financiera actualizada y ordenada.

Criterios de Aceptación:
El sistema debe permitir crear y modificar categorías asignadas a perfiles.
Cada Categoría debe estar asociada a un Usuario.
Las asignaciones deben incluir metadatos como fechas de inicio y fin.
Se debe respetar la integridad referencial y permisos de usuario al modificar/eliminar.
Validar que los presupuestos asignados no superen los límites financieros globales.
Mantener logs de cambios para auditoría.

Beneficios:
Control Financiero Detallado: Gestión de gastos y presupuestos.
Flexibilidad Operativa: Ajuste en tiempo real de asignaciones.
Mejora en Toma de Decisiones: Análisis financiero detallado.
Seguridad y Precisión: Control de asignaciones bajo permisos y trazabilidad.
Optimización de Recursos: Uso eficiente de recursos económicos.

Gestión de Perfiles
- Requerimiento Funcional: KuenteCO permitirá a los perfiles administrar sus datos.

- Historias de usuario:
Como perfil de negocio,  
Quiero listar mis datos,  
Para visualizar mis datos personales registrados.

Como perfil de negocio,  
Quiero cambiar mi contraseña mediante verificación por email,  
Para mantener la seguridad de mi cuenta.

Como perfil de negocio,  
Quiero gestionar mi imagen de perfil (subir, actualizar, eliminar),  
Para personalizar mi cuenta y facilitar mi identificación.

- Criterios de Aceptación:
Los perfiles pueden obtener sus propios detalles mediante autenticación.
Los perfiles pueden cerrar sesión, invalidando tokens y limpiando cookies.
Los perfiles pueden subir imágenes en formato multipart/form-data.

Beneficios:
Autonomía Operativa: Permite a los perfiles de negocio gestionar su propia información sin depender del usuario propietario, mejorando la eficiencia operativa.
Seguridad Granular: Cada perfil mantiene sus propias credenciales y sesiones independientes, reduciendo riesgos de seguridad compartida.
Personalización Individual: Los perfiles pueden personalizar su experiencia con imágenes y configuraciones propias, mejorando la identificación y satisfacción del usuario.
Trazabilidad Completa: El sistema de logs permite rastrear todas las actividades de cada perfil, facilitando auditorías y resolución de problemas.
Escalabilidad Organizacional: Facilita el crecimiento de la estructura organizacional del negocio sin comprometer la seguridad o funcionalidad.
Gestión de Accesos Distribuida: Permite delegar responsabilidades específicas a diferentes perfiles sin comprometer el control central.
Continuidad Operativa: Los perfiles pueden operar independientemente, garantizando que las operaciones del negocio continúen sin interrupciones.
Experiencia de Usuario Mejorada: Interfaces personalizadas y contextuales para cada perfil mejoran la usabilidad y adopción del sistema.

KuenteCO permitirá a los perfiles la gestión de transacciones para un usuario de negocio por medio de creación, modificación y eliminación de estas,

Las transacciones deben asociarse a perfiles de negocio correctamente identificados.
Debe permitir la categorización de transacciones por tipo y rubro.

Las actualizaciones de transacciones deben reflejarse inmediatamente en el histórico.

Seguridad Estricta: La gestión basada en roles asegura que solo los perfiles autorizados pueden hacer cambios críticos.
Eficiencia Operativa: La habilidad de modificar y ajustar transacciones rápidamente mejora la adaptación a cambios económicos o empresariales.
Mejor Auditoría: Los logs completos aseguran transparencia financiera y trazabilidad completa de las operaciones.

Registro y Gestión de Transacciones
KuenteCO facilitará a los usuarios el ingreso, gestión y visualización de sus transacciones financieras, permitiéndoles realizar un seguimiento preciso y actualizado de sus finanzas.
Historias de Usuario:
Como usuario,  
Quiero ingresar manualmente las transacciones con detalles específicos,  
Para llevar un seguimiento claro de mis movimientos financieros y categorizar mis gastos.

Como usuario,  
Quiero importar automáticamente las transacciones bancarias,  
Para mantener mis finanzas actualizadas sin necesidad de ingreso manual.

- Criterios de Aceptación:
El sistema permitirá la entrada manual de transacciones con fecha, monto y descripción detallada.
Las transacciones se podrán categorizar utilizando categorías predefinidas o personalizadas por el usuario.
Las transacciones podrán ser importadas automáticamente mediante integración segura con cuentas bancarias, como Bancolombia, mediante APIs.
Se proporcionará una URL de archivo con las transacciones obtenidas desde el banco.
Los usuarios podrán visualizar una lista completa de sus transacciones, filtrarlas por parámetros como fecha y categoría.
Los usuarios tendrán la capacidad de editar y eliminar transacciones si es necesario.
El sistema generará un resumen de transacciones que incluirá totales y clasificación por categorías, disponible bajo demanda para el usuario autenticado.
El acceso al resumen se restringe según el rol del usuario para mantener la integridad de los datos.

Beneficio:
Proporciona al usuario un control detallado de sus movimientos financieros, permitiéndole tomar decisiones económicas informadas con base en información precisa y organizada.

Gestión Avanzada de Deudas con Análisis de Riesgo
- Requerimiento Funcional:KuenteCO proporcionará un sistema integral de gestión de deudas que incluye análisis de riesgo automatizado, seguimiento de estados, y alertas proactivas para optimizar la salud financiera del usuario.
  - Historias de Usuario:
Como usuario,
Quiero registrar deudas con información detallada,
Para tener un control completo de mis obligaciones financieras.

Como usuario,
Quiero recibir análisis de riesgo de mis deudas,
Para tomar decisiones informadas sobre mi situación financiera.

Como usuario,
Quiero ver el estado actualizado de todas mis deudas,
Para planificar mis pagos de manera efectiva.

 - Criterios de Aceptación:
Los usuarios podrán registrar deudas con información completa: monto original, monto pendiente, tasa de interés, fechas de inicio y vencimiento, y descripción.
El sistema calculará automáticamente análisis de riesgo basado en montos, plazos y capacidad de pago.
Se generarán estados automáticos de deuda: PENDING (pendiente), PAID (pagada), OVERDUE (vencida), PARTIALLY_PAID (parcialmente pagada).
El sistema enviará alertas automáticas 7, 3 y 1 día antes del vencimiento.
Los usuarios podrán visualizar un dashboard con resumen de todas las deudas y su estado actual.
El sistema proporcionará recomendaciones para optimizar el pago de deudas basado en tasas de interés y fechas.
Se mantendrá un historial completo de pagos realizados y saldos restantes.
Los análisis incluirán métricas de salud financiera relacionadas con el nivel de endeudamiento

Beneficio: Ayuda a reducir riesgos de morosidad y mejora la salud financiera del usuario mediante una gestión organizada y recordatorios oportunos (Fabozzi & Peterson, 2013).

Control de acceso
- Requerimiento Funcional:  KuenteCO implementará un sistema de seguridad multicapa que incluye autenticación robusta, gestión avanzada de tokens JWT, blacklist de seguridad, y control granular de accesos basado en roles.
  - Historias de Usuario:
Como usuario,
Quiero autenticarme de manera segura con múltiples factores,
Para proteger mi información financiera sensible.

Como usuario,
Quiero que mis sesiones sean seguras y controladas,
Para prevenir accesos no autorizados a mi cuenta.

Como usuario,
Quiero recibir alertas de actividad sospechosa,
Para detectar y prevenir accesos maliciosos a mi cuenta.

 - Criterios de aceptación:
El sistema implementará autenticación JWT con tokens seguros que incluyan información de rol y expiración.
Se mantendrá una blacklist automática de tokens para sesiones terminadas o comprometidas.
Los usuarios podrán cerrar sesión de forma segura, invalidando inmediatamente todos los tokens activos.
Se implementará control de acceso basado en roles (RBAC) diferenciando entre usuarios personales, de negocio y perfiles.
El sistema detectará automáticamente patrones de acceso inusuales (IPs diferentes, horarios atípicos).
Se enviarán notificaciones inmediatas por email sobre inicios de sesión desde dispositivos no reconocidos.
Las contraseñas seguirán políticas estrictas: mínimo 8 caracteres, combinación de mayúsculas, minúsculas, números y símbolos.
Se implementará un bloqueo automático de cuentas después de 5 intentos fallidos de autenticación.
Los tokens JWT tendrán expiración automática configurable (por defecto 7 días).
Se mantendrá el log completo de todos los intentos de autenticación exitosos y fallidos.


Beneficio: Garantiza la protección de la información personal y financiera del usuario, fortaleciendo la seguridad de la plataforma (Pfleeger & Pfleeger, 2012).

5. Requerimientos Técnicos
5.1 Arquitectura del Sistema
El sistema KuenteCO estará basado en una arquitectura cliente/servidor, dividiendo las responsabilidades de presentación, lógica de negocio y acceso a datos, lo que permite una mejor escalabilidad, mantenibilidad y seguridad. Las capas son:
Capa de Presentación (Frontend): La interfaz web y móvil será desarrollada usando el framework Flutter para gestionar componentes dinámicos.
Capa de Lógica de Negocio (Backend): La lógica del sistema será gestionada por SpringBoot, conectando las interfaces de usuario con la capa de datos. El backend será responsable del manejo de la lógica financiera, el procesamiento de transacciones y la gestión de usuarios.
Capa de Datos (Base de Datos): Utiliza PostgreSQL como base de datos principal para almacenar la información relacionada con los usuarios, presupuestos, pagos, ingresos, y otros datos financieros y MongoDB  para almacenar el historial del servicio de chat.
5.2 Plataforma y Herramientas
Despliegue: El proyecto será empaquetado en un stack de Docker y será desplegado en AWS
Servidores de Base de Datos: Se utilizarán PostgreSQL y MongoDB como servidores de bases de datos, configurado dentro del stack de Docker para facilitar su gestión y portabilidad.
Framework de Desarrollo Backend: Para el desarrollo del Back-End se utilizará Spring Boot, un framework eficiente para aplicaciones de mediana y alta complejidad.
Frontend: La interfaz tanto web como móvil será construida con Flutter, aprovechando su capacidad para construir interfaces de usuario altamente interactivas y multiplataforma.
Control de versiones: Se utilizará Git como sistema de control de versiones, con repositorios alojados en GitHub para la colaboración del equipo.

5.3 Integraciones
Pasarelas de Pago: KuenteCO se integrará con Mercado pago para permitir el procesamiento seguro de pagos.
API de Bancos: Para automatizar la importación de datos financieros y sincronizar transacciones, se integrarán APIs del API Market de Bancolombia.
Servicio de Email: Para la activación o modificación de la contraseña, el sistema se integrará con servicios de email como SendGrid para recibir el código de validación.
Autenticación: Para la gestión de usuarios, se integrará JWT (JSON Web Tokens), permitiendo a los usuarios iniciar sesión en nuestro aplicativo.
Implementación de IA: Para la generación de informes en base a los datos financieros del usuario integramos OpenAI y Deepseek.
